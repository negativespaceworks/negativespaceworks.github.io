Driftile

色面がゆっくり漂う macOS スクリーンセーバーです。AbstractMotion とモンドリアンの色面分割から着想しています。

macOS 12+ 無料

背景

OS X の最初の年に、モンドリアンのようなスクリーンセーバーがありました。AbstractMotion（2001、Dan Abrahams-Gessel）。PowerPC 専用でした。Apple Silicon では動きません。

Driftile はその記憶から始まりました。色面が漂うものを、ネイティブの macOS .saver として組み直しました。パレットはモンドリアン、北斎、ホッパーなどにも向かいます。複製ではなく解釈であり、それらの権利者とは無関係のプロジェクトです。

プロファイル

組み込みのプロファイルは 6 つです。コンピュータではサムネイルにマウスを重ねると再生します。スマートフォンでは、見えているカードが再生されます。タップで一時停止や切り替えができます。

再生

Abstract Motion

斜めの線と、落ち着いた 12 色です。色相がゆっくり漂います。初期設定です。

再生

Classic Composition

原色とグレーです。太いグリッドがゆっくり組み変わります。

再生

Minimal Drift

モノクローム、広い余白、とても遅い動きです。

再生

Great Wave

北斎のプルシアンブルーです。飛沫のような短いフェードです。

再生

Nighthawks

ホッパーの深夜のカウンターです。直交する窓がゆっくり動きます。

再生

Color Field

線はありません。ロスコのオレンジと黄が呼吸します。

これらはブラウザ上のキャプチャです。インストールしたスクリーンセーバーとは構図が異なります。

オプション

6 つのプロファイルは出発点です。オプションでは動きを細かく指定できます。

  • パレット — Classic、Great Wave、Monochrome などを含む 8 パレット
  • 方向 — Free（斜めの線）または Composition（モンドリアンのような分割）
  • 隣接 — 隣のセルが同じ色を持ってよいかどうかです
  • 線数、着色確率、フェードイン、速度
  • 色相ドリフト と 線幅（0 で線は消えます）

カスタムは、自分の設定を 1 スロット保持します。

インストール

このビルドは公証されていません。.saver をダブルクリックしないでください。 Gatekeeper が、確認なしでゴミ箱へ移すことがあります。

  1. ダウンロードした zip を展開します。
  2. ターミナルで検疫を外し、Screen Savers フォルダへコピーします（展開した場所が違う場合はパスを合わせてください）。
xattr -cr ~/Downloads/Driftile.saver
mkdir -p ~/Library/Screen\ Savers
rm -rf ~/Library/Screen\ Savers/Driftile.saver
cp -R ~/Downloads/Driftile.saver ~/Library/Screen\ Savers/
  1. システム設定 → 壁紙 → スクリーンセーバ で Driftile を選びます。出ないときは、システム設定を ⌘Q で完全に終了してから開き直してください。

バージョンはオプション画面のタイトル、または plutil -p ~/Library/Screen\ Savers/Driftile.saver/Contents/Info.plist の CFBundleShortVersionString で確認できます。
