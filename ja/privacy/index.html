Negative Space Works（「私たち」）は、Kompo と Driftile を含む Mac ソフトウェアをつくっています。 このポリシーは、情報の扱いを説明します。方針が変わったときは、このページを更新します。

アプリについて

Kompo と Driftile は、あなたの Mac のうえで動くように設計しています。アカウントは不要で、第三者の解析や広告 SDK は入れていません。

  • Kompo は、スペクトラムアナライザを描くために、Mac 上の Music.app または Spotify から音声を読みます。 その音声は端末内で処理します。設定は Mac に残ります。
  • Driftile はスクリーンセーバーです。設定は Mac に残ります。

これらの製品から、音声、画面の内容、アプリの設定をネットワーク経由で受け取ることはありません。

このウェブサイト

このサイトは静的なウェブサイトです。アカウントやフォームはありません。

ページビュー、参照元、国、ブラウザ、Core Web Vitals など、集計されたトラフィックと性能を見るために Cloudflare Web Analytics を使っています。 Cookie は使わず、ブラウザのフィンガープリントも取らず、他のサイトをまたいだ追跡もしません。 Cloudflare はエッジで IP アドレスを捨て、この解析データと一緒には保存しません。

ホスト（GitHub Pages）と Cloudflare（DNS と CDN）は、IP アドレスやリクエストされたページなど、通常のリクエストログを残すことがあります。

En または Ja を選んだ場合、その選択はブラウザ内だけに残ります。私たちには送られません。

メール

support@negativespace.works に書いた内容（アドレス、本文、添付など）は、返信のために受け取ります。 そのメールはサポートに使い、広告には使いません。

購入

Mac App Store でソフトウェアを買う場合、決済とアカウント情報は Apple のプライバシーポリシーのもとで Apple が扱います。 カード情報は受け取りません。
