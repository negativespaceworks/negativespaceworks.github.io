Install

This build is not notarized. Do not double-click the .saver. Gatekeeper may move it to the Trash with no prompt.

  1. Unzip the download.
  2. In Terminal, clear quarantine and copy it into the Screen Savers folder (adjust the path if you unzipped elsewhere).
xattr -cr ~/Downloads/Driftile.saver
mkdir -p ~/Library/Screen\ Savers
rm -rf ~/Library/Screen\ Savers/Driftile.saver
cp -R ~/Downloads/Driftile.saver ~/Library/Screen\ Savers/
  1. System Settings → Wallpaper → Screen Saver, then choose Driftile. If it does not appear, quit System Settings completely with ⌘Q and open it again.

Check the version in the Options sheet title, or with plutil -p ~/Library/Screen\ Savers/Driftile.saver/Contents/Info.plist and CFBundleShortVersionString. This page ships 2.0.1.
