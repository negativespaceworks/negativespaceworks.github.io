Driftile

A macOS screen saver of color fields that drift. Inspired by AbstractMotion and Mondrian’s color divisions.

macOS 12+ Free

Background

There was a Mondrian-like screen saver from the first years of OS X: AbstractMotion (2001), by Dan Abrahams-Gessel. It was PowerPC only. It does not run on Apple Silicon.

Driftile started from that memory. Color fields that drift, rebuilt as a native macOS .saver. The palettes also look at Mondrian, Hokusai, Hopper, and others. They are interpretations, not copies, and this project is not affiliated with those estates.

Options

The six Profiles are starting points. In Options you can also set the motion in detail.

  • Palette — eight palettes, including Classic, Great Wave, and Monochrome
  • Direction — Free (diagonal lines) or Composition (Mondrian-like splits)
  • Adjacency — whether neighboring cells may share a color
  • Lines, color chance, fade-in, and speed
  • Hue drift and line width (zero hides the lines)

Custom keeps one slot of your own settings.

Install

This build is not notarized. Do not double-click the .saver. Gatekeeper may move it to the Trash with no prompt.

  1. Unzip the download.
  2. In Terminal, clear quarantine and copy it into the Screen Savers folder (adjust the path if you unzipped elsewhere).
xattr -cr ~/Downloads/Driftile.saver
mkdir -p ~/Library/Screen\ Savers
rm -rf ~/Library/Screen\ Savers/Driftile.saver
cp -R ~/Downloads/Driftile.saver ~/Library/Screen\ Savers/
  1. System Settings → Wallpaper → Screen Saver, then choose Driftile. If it does not appear, quit System Settings completely with ⌘Q and open it again.

Check the version in the Options sheet title, or with plutil -p ~/Library/Screen\ Savers/Driftile.saver/Contents/Info.plist and CFBundleShortVersionString.
